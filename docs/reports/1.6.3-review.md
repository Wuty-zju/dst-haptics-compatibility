# 1.6.3 维护复审

2026-11-21，从 1.6.2 发布后的 main `6a4bd00` 开始。改动针对现有震动的生命周期、去重和正式包边界。

## 原始依据

- 本机 DST `762172`，Steam build `26474873`。Steam UpToDateCheck 返回 `up_to_date=true`。直接解读安装包，逐文件对照 **4,109** 个成员及保存的快照，文件名和字节一致。506 条定义对应 503 个唯一事件。
- 最新本地客户端日志是 11 月 18 日凌晨，SHA-256 与上次归档一致。两份有效样本记录工坊 `3805091756` 的 1.5.0 共 14 次加载及初始化，另一份是已归档旧样本。订阅目录的 `modinfo.lua` 仍标 1.5.0。本轮未发现新附加日志、待处理 GitHub issue 或补充评论。
- 本地共核查 19 条既有分支引用，18 条已在基线历史内。唯一例外 `codex/160-localization` 的补丁经 `git cherry` 核对等价。沿用历史工作树与已发布成品，新增独立维护工作树。[任务合同](../tasks/2026-11-21-release-1.6.3.md)

## 已确认并修复的问题

| 范围 | 原版依据或复现 | 修复 |
|---|---|---|
| 换角色后的雨声与其他具名循环 | `player_common.lua` 776–827 在同一世界依次发旧玩家失活、换 `ThePlayer`、新玩家激活。`weather.lua` 256–269 与 `caveweather.lua` 187–197 对同一雨声句柄继续写参数。1.6.2 失活时清空全部循环，现存雨声回放没有输出 | 原版无缝标记存在时保留世界循环，释放旧玩家及本地专属记录。采样重新核对真实句柄和实体资格。普通失活与世界退出仍清空 |
| 模式交接时持续声起点丢失 | 从 Native 或 Diagnostic 起声，切回 Compatibility 时原声句柄仍在播放。原版只继续写雨量，1.6.2 缺少记录 | 只记真实的具名起声及后续参数。兼容恢复后核对仍在播放的句柄。验证原生、诊断和总开关关闭期间没有兼容马达调用或循环播放探测 |
| 实体移除后的混合尾段 | 薇洛打火机的 `torch` 在 `lighterfire_common.lua` 69–70 建立，`lighter.lua` 200–203 卸下时直接移除特效。回放中已排队的弱尾段还能下发一次 0.05 秒脉冲 | 只在发送延迟段时核对原混合的实体支撑。已移除的来源无法独自让旧幅度输出，同幅度且覆盖这一段的有效来源仍可正常输出。同名重播也必须是当次采样的声音实例，才有资格支撑旧计划。下一次采样处理其余有效贡献 |
| 输出失效与跨来源去重 | 真实 Wilson 受击、Woby 脚步和 FocalPoint 烧伤回放，共 16 项条件。1.6.2 只通过 7 项。换设备或暂停恢复后，同名真实事件可被旧缓存吞掉。被拒的同源重复还可刷新跨来源窗口 | 三类记录与输出代次一同失效。只有通过同源去重的事件才更新跨来源历史。同一代原始声音和动作桥的重复仍抑制。提交版回放 **16/16** |
| 发布包输入与可复建性 | 同一个未跟踪 Lua 探针被递归复制为第 24 个包成员。1.6.2 的校验只依据路径形状，接受了这个文件 | Git 工作树打包跟踪的 Lua，CI 核对精确成员集合。新构建 ZIP 名称、顺序与时间固定。改变源文件修改时间后重建，ZIP 和校验文件相同。规范化包内文本后，旧 Windows worktree 和同一 Git 树的源码归档也生成相同 ZIP。保持已存在产物的覆盖保护 |

## 保留的设计及理由

| 既有范围 | 本轮复核结果 |
|---|---|
| 原版索引、包络和 14 个新增事件 | 重跑 506 条定义、41,492 次倍率断言，并用实际运行时导出对照。保留上一版经核对的 503 事件表。原版重复项与 C++ 映射边界仍有记录。[事件对照](../audit/DST-Haptics-Event-Audit-1.6.2.csv) · [14 个事件触发位置](../audit/1.6.0-trigger-paths.md) |
| 工具、战斗和受击动作桥 | 原始动作成功复制确认与本地动作身份分开验证。工具仍要通过原版声音或已有的动作上下文。一般 attacked/ATTACK 估计维持可选且默认关闭，特殊受击优先只针对当前输出代次 |
| Boss、空间和 UI | 仍按实际原声或已审计句柄处理。Shrouden 的 `loop` 和 `bigloop` 在原版实体路径中有各自起停，现有观察不需改。保留空间、音量和本地归属的策略。远程句柄可见性仍需游戏内记录 |
| 设备、设置、翻译和混音 | Xbox/DS4/DS5 的 Legacy Rumble 曲线、设置键和中英界面沿用。设备交接测试继续要求原生恢复后不调用共享停止。循环的正常增益采样、独立时长和同名替换均保留 |
| 工作区及历史 | 完成上一版候选 26 项的迁移和逐文件核验。旧 Git 分支、原版快照、日志和正式成品保持可追溯。原始证据仍在本机忽略路径 |
