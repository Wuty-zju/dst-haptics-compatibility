# 1.5.0 审核与待验收记录

状态：按用户 2026-09-20 最新指示缩减实机流程并进入发布。代码证据不替代主观手柄体感；未测试的硬件组合如实保留。

## 要求一

18 个强度/时长轴具备 41 档，默认 100%，范围 0%–200%。配置读取支持旧字段、缺失默认与异常值。当前原版 492 条定义的分类轴双向调节共 40,344 次断言通过。未知分类回退玩家设置；工具/战斗与原版类别相乘。

单次包络延迟和宽度同倍率变化；循环单次宽度独立改变，按各自到期时间进行最大值混合。KillSound、KillAllSounds、音量/参数、设置变化、暂停、断连、世界卸载均参与取消或刷新。0% 不产生马达调用或单次尾部任务。

Xbox、DS4、DS5 的单调响应、原版 0.5/1/1.5/2/2.5/3/10 层级、普通强度的全部 41 档、通用回退及 PS5 两种类型别名通过自动测试。多层反馈来自原版兼容包络，DS4/DS5 使用不同 gamma/gain/最短脉冲补偿；这些经验参数未被物理测量证明是完美校准。

待验证：真实 Xbox/DS4/DS5 USB、蓝牙和 Steam Input 体感。当前系统枚举到 Xbox 与 DualSense，未发现 DS4。100% 是未加用户倍率的兼容基准；Lua 没有提供原生马达逐采样输出，所以绝对强度和时长等同原生的要求仍无法证明。

## 要求二

- 输入来源：动态 haptics.lua；保留原版字段和服务器确认桥接，未加入按键或预测动画震动。
- 可维护性：配置读取、类型倍率、循环混音拆分为独立模块；profile 初始化缓存。
- 热点：未匹配声音哈希旁路，循环混音 O(n log n)，调试关闭不格式化事件日志，过期去重缓存周期清理。
- 兼容性：前后链式 SoundEmitter hook 保留 nil、尾部变参和返回值；重复安装不增加 worker；纯客户端与原生/兼容模式保留。
- 生命周期：修复暂停期事件排队、恢复旧尾部与其他玩家受伤干扰本地仲裁；仍需实机进入/退出世界与切洞穴验证。
- 工具链：Lua 5.1 检查默认当前仓库；版本从 modinfo 读取；打包不包含原版脚本/WAV；双语说明、图标和许可证作为必需内容。
- 性能证据：模拟引擎接口下，200,000 次普通声音 0.078 秒；64 贡献混音 10,000 次 0.324 秒。不是实际游戏帧率或物理延迟测量。
