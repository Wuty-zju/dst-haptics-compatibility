# Steam Workshop Distribution / 创意工坊分发

This project targets the Don't Starve Together Workshop (App ID `322330`) as a ready-to-use, client-only utility mod.

## Content package

The Workshop content folder must contain the runtime mod at its root. Do not wrap it in another repository directory.

Required runtime files:

- `modinfo.lua`
- `modmain.lua`
- `scripts/`

Recommended user-facing files:

- `README.md`
- `LICENSE`
- Klei-generated `modicon.tex` and `modicon.xml`

Repository-only files such as `.git`, `.github`, `tests`, `tools`, `docs`, build artifacts, local logs and extracted Klei data are excluded from the content upload.

## Metadata checklist

- Title: `DST Haptics Compatibility / 手柄震动兼容`
- Type: client-only utility
- Tags: `utility`, `client_only_mod`
- Visibility: owner choice; test privately before public visibility
- Version and change note must match `modinfo.lua` and `CHANGELOG.md`
- Preview image and description must not imply Klei endorsement or include redistributed Klei assets
- Do not bundle original `scripts/haptics.lua` or Haptic WAVs

## Upload boundary

Steam treats a Workshop item as a content folder plus title, description, tags, visibility and preview metadata. Creating or updating the item also requires the contributor to accept the Steam Workshop legal agreement. The repository therefore prepares and validates the content folder, but an authenticated owner Steam session performs the actual upload.

The release package is generated by `tools/build_release.ps1`. Its Workshop directory is the only folder intended for content upload.
